# 期权交易策略说明

## 策略框架概述

当前 MVP 实现三类主要策略，LLM 会综合多维度指标进行判断，并给出带数据支撑的推理。

---

## 策略 1：卖出高 IV（Short Premium）

### 原理
当隐含波动率（IV）显著高于历史波动率（HV）时，期权被"高估"。期权卖方可以收取 IV 溢价，随着时间流逝（Theta）和波动率回归，获得盈利。

### 触发条件
- `iv_percentile > 70`（当前 IV 超过过去一年 70% 的时间）
- `iv_atm - hv20 > 5%`（IV 比 HV 高出 5 个百分点以上）
- `days_to_expiry` 在 14-60 天之间

### 常用结构
| 结构 | 说明 | 适用场景 |
|------|------|---------|
| Strangle（宽跨） | 同时卖 OTM Call + OTM Put | 标的无明显方向，宽幅震荡 |
| Straddle（跨式） | 同时卖 ATM Call + ATM Put | IV 极高，期望大幅回落 |
| Covered Call | 持有标的 + 卖 OTM Call | 偏多、想增加收益 |
| Cash-Secured Put | 备兑卖 OTM Put | 偏多、愿意低位接货 |

### 风险
- 标的暴涨/暴跌超出行权价范围时亏损无限制（Strangle/Straddle）
- 黑天鹅事件（突发新闻、政策）可能导致 IV 不降反升
- **止损建议**：损失超过最大潜在收益 2 倍时止损

---

## 策略 2：买入低 IV（Long Premium）

### 原理
当 IV 处于历史低位时，期权被"低估"，买入期权的期望收益更高。通常在已知催化事件（财报、政策会议、重要数据发布）前布局。

### 触发条件
- `iv_percentile < 30`（当前 IV 低于过去一年 70% 的时间）
- 有明确的催化事件预期
- `days_to_expiry` 在 20-90 天之间（时间价值损耗慢）

### 常用结构
| 结构 | 说明 |
|------|------|
| Long Straddle | 同时买 ATM Call + ATM Put（方向中性，博大波动）|
| Long Strangle | 同时买 OTM Call + OTM Put（成本低，需更大波动）|
| Long Call/Put | 有方向判断时的单腿 |

### 风险
- 时间价值每天流失（Theta 损耗）
- 若标的未出现预期波动，亏损全部权利金
- 买入时机不对（IV 继续下降）

---

## 策略 3：趋势方向策略

### 原理
当标的有明确的短期趋势信号，且 IV 处于合理水平时，用期权代替直接买卖标的，获得杠杆收益同时限制最大亏损。

### 触发条件
- 趋势信号：MA5 > MA20 > MA60（多头排列）或反向（空头排列）
- RSI14 > 70（超买，看回调）或 RSI14 < 30（超卖，看反弹）
- IV 处于中等水平（不太贵也不太便宜）

### 常用结构
| 方向 | 结构 |
|------|------|
| 偏多 | Long Call / Bull Call Spread |
| 偏空 | Long Put / Bear Put Spread |

## 筛选过滤规则

在任何策略分析之前，自动过滤掉以下合约（`config/strategies.py` 中配置）：

| 条件 | 阈值 | 原因 |
|------|------|------|
| 成交量 | < 500 | 流动性差，买卖价差大 |
| 到期天数 | < 7天 | Gamma 风险极大，不适合普通策略 |
| IV | < 1% | 数据无效（深度实值合约IV不可靠）|
| Moneyness | > ±15% | 深度虚值合约，流动性差 |

## LLM 的决策逻辑

LLM 接收预计算的 MarketSnapshot，按以下框架分析：

1. **波动率状态**：IV vs HV 的相对水平，IV 分位数
2. **标的趋势**：技术指标确认方向
3. **候选合约筛选**：哪些合约的 Greeks 适合对应策略
4. **综合判断**：是否有多个指标共振？信号强度如何？
5. **风险评估**：潜在最大亏损、止损位设置

输出格式严格为 JSON，包含具体合约代码、操作方向和自然语言推理。

---

## 信号评级

| 评级 | 含义 | 触发条件 |
|------|------|---------|
| **high** | 强烈推荐 | 多个指标共振，IV/趋势/时机都清晰 |
| **medium** | 建议关注 | 2个以上指标支持，但有一定不确定性 |
| **low** | 仅供参考 | 单一信号，不确定性较大 |

原则：**宁可错过机会，不推荐低质量信号**。当无明显机会时，LLM 会明确输出"当前无推荐信号"并说明原因。

## Phase 2 预计扩展策略

- **铁鹰式（Iron Condor）**：同时卖 OTM Call Spread + OTM Put Spread，收取有限权利金，风险有限
- **日历价差（Calendar Spread）**：利用不同到期月份 IV 差异套利
- **比例价差（Ratio Spread）**：非对称头寸，针对特定波动率观点
