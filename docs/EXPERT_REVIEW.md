# AI Trading Agent - 期权交易策略审查与迭代评估报告

## 一、 项目背景与系统定位
本项目是一个 AI 驱动的中国期权市场（ETF与期货期权）交易信号 Agent。
我们的核心设计原则是：**确定性的代码负责数据抓取和计算，大模型（LLM）负责分析和决策。**
系统并不会自动下单，而是定时扫描市场行情，计算各项衍生品指标，经过初步过滤后，将浓缩后的“结构化数据”喂给 Claude/GLM 模型，由模型输出带有推理逻辑的交易建议（买卖方向、具体组合结构、开仓逻辑与风险提示），最终推送到企业微信或用户接收端。

我们希望借助专家的经验，审视当前的**数据处理逻辑**、**策略框架**以及**喂给大模型的提示词**是否符合真实专业交易员的思考框架。

---

## 二、 当前数据链路与处理流程

1. **获取基础行情 (Fetcher)**
   - **标的物**：获取 ETF 或期货的实时价格、成交量，以及历史日线数据。
   - **期权T型报价**：获取各个月份、各行权价的 Call/Put 实时行情（最新价、成交量、持仓量、隐含波动率 IV、各项 Greeks 等）。

2. **指标计算与压缩 (Compute)**
   - **标的技术指标**：基于标的日线计算 MA5, MA20, MA60, RSI(14)，判断简单的多空趋势排列。
   - **波动率指标**：计算历史波动率（HV10, HV20, HV60）；将当前平值 IV 与过去一年的 IV 进行比较，计算出 **IV Rank** 和 **IV Percentile**。

3. **规则筛选 (Screening)**
   为防止大模型幻觉和降低 Token 开销，我们在发给 LLM 前会用硬规则过滤掉不适合交易的合约（流动性差或风险过高）：
   - 过滤成交量 < 500，持仓量 < 1000 的合约（避免买卖价差过大）。
   - 过滤到期日 < 7 天的末日期权（Gamma 风险过高）。
   - 过滤虚值/实值程度太深的合约（仅保留平值 ATM 附近 ±3 档）。
   - 过滤 IV 数据明显异常（如 IV < 1%）的无效合约。

4. **大模型决策 (Analyst)**
   把压缩并过滤后的**市场状态快照**发给 LLM，LLM 结合 Prompt 的规则，输出标准化的 JSON 信号与推理逻辑。

## 三、 当前实施的策略框架

目前系统要求 LLM 主要寻找以下三类机会：

### 1. 卖出高 IV（Short Premium）
- **触发条件**：当前 IV 分位数 > 70%，且当前 ATM IV 高于 20日历史波动率（IV - HV20 > 5%），合约到期日在 14-60 天之间。
- **交易结构**：做空波动率（如 Strangle, Straddle）或配合标的持仓做 Covered Call / Cash-Secured Put。
- **风险考量**：标的暴涨暴跌导致的无限制亏损；模型会给出止损建议。

### 2. 买入低 IV（Long Premium）
- **触发条件**：当前 IV 分位数 < 30%，到期日 20-90 天（避免时间价值快速衰减）。
- **交易结构**：做多波动率（Long Straddle, Long Strangle）或判断有方向时单买单腿。

### 3. 趋势方向策略（Directional）
- **触发条件**：标的物出现明确技术趋势（如均线多头/空头排列），或 RSI 超买超卖指标共振，且当前 IV 不算过高。
- **交易结构**：用期权替代现货获取杠杆（买入 Call/Put）或降低成本的垂直价差（Bull Call Spread / Bear Put Spread）。

## 四、 喂给 LLM 的提示词与上下文格式

**这是决定 AI 如何思考的最关键部分。**

### 1. 提供给 LLM 的系统设定 (System Prompt 完整版)
代码中的完整设定如下：

```text
你是一位专业的期权交易分析师，专注于中国期货和ETF期权市场。

## 你的角色
分析预计算好的市场数据，识别交易机会，给出带有清晰推理的交易信号。
你不需要自己计算任何指标——所有指标已经由程序预计算完成并验证。
你专注于模式识别、风险评估和交易逻辑分析。

## 策略框架（按优先级排序）
1. **卖高IV策略**：当 iv_percentile > 70 且 IV 明显高于 HV 时，寻找卖出宽跨式(strangle)/跨式(straddle)机会
2. **买低IV策略**：当 iv_percentile < 30 且可能有催化事件时，考虑买入期权
3. **趋势方向策略**：当标的趋势明确且 IV 合理时，考虑方向性期权交易
4. **回避规则**：成交量太低(volume < 500)、临近到期(<7天，除非有意为之)的合约不推荐

## 输出格式要求
请严格以 JSON 格式输出，schema 如下：
{
  "market_assessment": "对当前市场状态的整体判断（中文，2-3句话）",
  "signals": [
    {
      "action": "策略类型，如 sell_strangle / buy_call / sell_put / iron_condor 等",
      "legs": [
        {"code": "合约代码", "name": "合约名称如50ETF沽4月3000", "direction": "buy 或 sell", "quantity": 1}
      ],
      "rationale": "交易理由（中文，3-5句话，包含关键数据支撑）",
      "risk_warning": "风险提示和止损建议",
      "confidence": "high / medium / low",
      "urgency": "immediate / within_session / next_session"
    }
  ],
  "no_action_reasons": ["如果没有推荐信号，说明原因"]
}

## 重要原则
- 宁可错过机会，也不推荐低质量信号。如果没有明显机会，signals 为空并在 no_action_reasons 中说明
- 每个信号必须有具体的数据支撑（引用提供给你的指标数值）
- confidence 要诚实：只有在多个指标共振时才给 high
- 必须输出合法 JSON，不要输出其他多余内容
```

### 2. 用户级提示词 (User Prompt) 
每轮扫描时动态注入的提问：

```text
当前时间: {scan_time}

以下是 **{underlying_name}** 期权市场的分析数据：

{market_snapshot_json}

请分析当前市场状态，识别交易机会，并给出你的判断。
如果没有明显机会，请明确说明原因。

请以 JSON 格式输出。
```

### 3. 提供给 LLM 的数据包结构 (Market Snapshot 示例)
LLM 每轮获取到的 JSON 态势感知数据包类似如下结构：
```json
{
  "scan_time": "2026-04-13 14:30:00",
  "underlying": {
    "code": "510050", "name": "50ETF", "price": 2.501,
    "ma5": 2.49, "ma20": 2.45, "ma60": 2.40,
    "rsi14": 65.2, "trend": "bullish"
  },
  "volatility": {
    "hv10": 12.5, "hv20": 13.1, "hv60": 15.2,
    "iv_atm": 18.5, "iv_percentile": 82.5, "iv_rank": 75.0,
    "iv_vs_hv": "iv_premium(+5.4)"
  },
  "candidates": [
    // 包含几十个经过初步过滤的合约的具体信息
    // 字段：代码, 类型(C/P), 行权价, 剩余天数, 最新价, IV, 成交量, 持仓量, Greeks(Delta/Gamma/Theta/Vega)
  ]
}
```

## 五、 计划扩展的方向 (Phase 2)
在第一版跑通自动分析与推送链路后，我们计划进行如下扩展：
1. **日历价差 (Calendar Spread)**：引入不同月份合约的 IV 曲线（Term Structure）对比。
2. **波动率偏斜度 (Volatility Skew/Smile)**：对比深度虚值 Put 和 Call 的 IV 差异，分析市场情绪偏好。
3. **多腿结构化**：引入铁鹰式 (Iron Condor)、比例价差等复杂结构。

因为开发团队主要精力在工程化（数据获取、多并发调度、大模型解析），在**期权交易的内核**上，非常希望能得到专家的指点：

2. **策略规则的现实性**
   - "卖高IV" 设定 `iv_percentile > 70` 且 `IV - HV > 5%` 是否合理？会不会在黑天鹅行情被一波带走？如何通过代码设定更好的前置规避条件？
   - 我们的硬性过滤规则（剔除末日 < 7天、仅留平值上下3档）会让我们错过很好的机会吗？

3. **大模型 Prompt 审查与优化**
   - 当前的系统提示词（System Prompt）是否捕捉到了期权交易员的核心逻辑？
   - 您是否有一些特定的“思考步骤”或“思维模型”（如：先看宏观方向 -> 再看波动率偏斜 -> 最后挑特定Delta和Gamma的合约）？我们可以将其转化为思维链（Chain of Thought）补充到 Prompt 中，让 AI 分析更贴近实战。

4. **超额收益方向**
   - 针对国内的期权市场（上证50/沪深300 ETF期权、常见商品期权），当前市场结构下，什么样的策略最容易获得稳定收益？我们最应该教 AI 重点去寻找哪种“错配机会”？
